# 自有素材库

讲述者自己的、能在不同片子里反复用的素材都放这里，例如截图、照片、录屏片段、数据截图。找素材时先查 [index.csv](index.csv)，库里有的就不去搜库存素材，也不去生成，见 [素材规则](../docs/content-packaging/README.md) 第 2 步。

只服务一条片的素材，仍然放在那条片的 `projects/<片名>/assets/` 里。哪条片的素材以后还会用到，就挪到这里，再登记进索引。

## 分类

一个分类一个文件夹，用到了再建，不提前建空的：

| 文件夹 | 放什么 |
|---|---|
| `nomi/` | Nomi 的产品界面、GitHub、用户和社群、合作、融资与孵化 |
| `system/` | 剪辑系统、仓库、组件样张、AI 协作过程的截图 |
| `career/` | 求职、简历、录用意向、工作经历 |
| `trading/` | 交易经历、交易记录、复盘 |
| `account/` | 自己账号的数据、后台、评论 |
| `life/` | 生活、学习、留学、个人照片 |

某一类东西攒多了，或者放在哪一类都别扭，就新建一个文件夹，同时把它补进上表。

## 放进来时

- **文件名**：`<日期>-<英文短名>.<扩展名>`。日期写素材里那件事发生的日子，例如 `2026-10-28-yunhan-incubator-application.png`。
- **登记**：在 `index.csv` 里加一行。
  - `facts` 只写画面上真能看到的事实；
  - `limits` 写它证明不了什么、不能怎么说；
  - `privacy` 写上屏前要遮住哪里；
  - `used_in` 记它用进了哪条片，用一次补一次。
- **隐私**：手机号、账号、金额、别人的名字和头像，上屏前在剪辑里单独加遮挡层。库里存原图，不在原图上涂改。
- **大文件**：视频原片、`.mp4`、`.mov` 不进 Git，放 `library/<分类>/media/` 本地，索引里照样登记。

## 找素材

```bash
grep -i "nomi" library/index.csv        # 按关键词找
column -s, -t < library/index.csv | less -S
```
