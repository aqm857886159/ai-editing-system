## 3. 怎么说话

- **开头：** 喜欢怎么开头，比如第一句就给结论，或者从一件刚发生的事讲起。
- **节奏：** 语速、一条多长。
- **录制方式：** 照稿念，还是看提纲用自己的话讲。
- **口头禅和脏话：** 留不留。
- **容易出问题的地方：** 比如开头铺垫太长、数字凭记忆说错。

## 4. 写稿时怎么配合

- 第一句写成你会说的话：一件具体的事，或一句判断。
- 精确的数字、原文交给画面，嘴上说取整的数。
- 留“亲历位”：哪里该讲你自己的经历，就标出来。
