# L-012 生图任务完成后，还要检查封面

历史生成案例出现过人物过锐、文字和比例需要返修；不能由一次可用结果推导“中文一次就准”或固定生成耗时。工具与模型按当前可用能力和授权选择，APIMart 等渠道说明见 [providers](../content-packaging/providers.md)，不在 lesson 冻结 API。

保留用户认可的方向：简洁、标题大、本人像自然精修。身份参考用获准原照或清晰原片帧；每个比例写独立构图和精确文字。生成后检查实际尺寸、字形、相似度、裁剪及小图可读性。创意和新提示词规则统一在 [L-013](L-013-cover-master-first.md) 与发布 Skill，不在这里再维护一套步骤。
