# L-002 句内抠字 = 卡顿、剪辑感重
- **场景**：为了缩短，把一句话里的赘词一个个删掉，拼成很多 1–2 秒的小片段（如「你隔一段时间 / 重新让AI去帮你 / 校准一轮」）。
- **用户反馈**：「中间有些不太丝滑，有卡顿、裁切，剪辑感有点重。」
- **根因**：每个句内剪点都有韵律断裂；碎片越多越明显。
- **做法**：
  1. 取舍以**句子为单位**；剪点放在句末停顿处。
  2. 句内删除后听起来断裂 → 优先恢复连续原声，或按整句取舍；片段长度只帮助定位，不能用“少于七秒”机械决定。保留的口癖按原声转写，字幕不另行删改意思。
  3. 只压明显多余的长停顿，保留呼吸与操作理解需要的时间；0.6s 是历史起始参数，不是所有停顿的裁切线。
  4. 允许保留少量「呃」，别为了干净切碎。
