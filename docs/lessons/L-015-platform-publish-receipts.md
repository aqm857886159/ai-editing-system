# L-015：上传完成不等于发布，封面上传不等于比例正确

2026-10-21 四平台实测：小红书横屏视频会把上传的 3:4 封面默认裁成 4:3，切掉标题；进入“裁剪”选 3:4，保存后查看“封面预览”才修好。B站标题也曾在填入后回退为视频文件名，必须移焦读回。

抖音发布后内容管理可能短暂显示旧列表，搜索标题等结果更新即可核实，不能因此重投。小红书 URL 原有的 `published=true` 与本次结果无关；用笔记管理的同名作品和审核状态判断。X 的编辑器未提供自定义缩略图入口，记录首帧/平台默认回退，不能声称已经套用宽屏封面。

规则入口统一放在 [video-to-platform-package](../../skills/video-to-platform-package/SKILL.md)，详细平台操作放其 references。每次留下实际字段、成片 SHA-256、平台状态、作品入口、时间和截图；提交、审核、公开是不同状态。不要把这些一次性的 UI 标签扩大成永久选择器。
