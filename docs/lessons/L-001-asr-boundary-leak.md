# L-001 剪口边缘的字会漏进字幕（以及几十毫秒的音频）
- **场景**：A-roll 删掉若干字后，被删字的 ASR 时间戳与保留片段重叠几十毫秒 → 字幕卡片带出 `就是/50/你/然后/对/帮…` 这类残字。
- **发生了什么**：字幕里出现「…改不动了就是」「我一个人写了一个 50」，实际声音只漏 ≤ 14ms，但字幕看得见。
- **怎么做**：在字号／行数稳定后读取全部字幕，结合剪后声音查首尾与剪口。只清理已被剪掉却被映射带出的文字和空／极短技术卡；仍能听见的口癖不是技术残字，不批量删除。改样式重新分卡后再查受影响边界。
- 原生字幕和外部 SRT 若有清理差异，分别保留版本与原因。完整字幕、强调与更正的分工见 [视觉编辑指南](../visual-editing.md)，不能把边界修复变成整句改述。
