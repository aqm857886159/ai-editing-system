# L-013 参考旧作品的方法，为本期写新提示词

早期“先找母版只改字”的要求已由用户在 2026-10-21 的确认更新：默认重新构思并用 AI 生图，不继续沿用旧封面改字或拼凑。保留此路径供旧引用访问，现行制作步骤归 [发布 Skill](../../skills/video-to-platform-package/SKILL.md) 第 5 节。

旧作品可帮助理解留白、字级、人物比例和克制风格；新提示词必须说明本期观看理由、视觉锚点、精确标题、人物参考用途及各比例构图。一个主判断、一个视觉锚点，辅助字非必需，不把流程摘要塞成封面。

`adapt_master_covers.py` 仅保留为用户明确选择复用旧母版时的历史工具，不是默认生成入口。新方案仍需三比例实际尺寸、缩略图可读性和平台裁剪检查。
