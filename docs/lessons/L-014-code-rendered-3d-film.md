# L-014 代码渲染 3D 短片：竖屏构图、剪影、静音的坑

来源：2026-10-09 大理论时代短片（`projects/2026-10-09-big-theory-era/short-film/`）

1. **9:16 的水平视角很窄。** 垂直 FOV 38° 时水平只有约 21.6°，人和主体只要差十几度就有一个出画。先按角度算构图（人在 0.2–0.3、主体在 0.55 以后），不够就拉远机位或临时换广角（50°）。
2. **两个暗色剪影在同一条视线上会合成一个。** 天亮镜头里人站在石块正前方，人就「消失」了。剪影镜头要让主体之间露出亮背景（地平线雾带、天空），光源方向可以为构图改。
3. **暗物体上的暖光点光会把剪影照成木头模特。** 情绪光要弱（照地面多于照人），人保持剪影。
4. **航拍时黑色物体在黑地面上看不见。** 远景把地面提亮成月光下的浅灰，人和石碑才像记号一样印在地上；同时压暗前景的发光粒子。
5. **场景里的东西不要在镜头贴地后突然隐藏。** 雾不浓到能挡住 10 米外的东西，要在镜头移动途中淡出。
6. **刻在面上的文字平面会深度打架。** 偏移 ≥ 2 cm，相机 near ≥ 0.3。
7. **「停转 / 静音」要把混响尾巴一起切掉。** 停转前后分两条总线各自做混响，停转后把前一条整条清零。合成钢琴音量偏大，要单独压低。
8. **字幕和画面里的刻字会撞。** 每段字幕先在静帧里看和主体的位置关系，必要时断行或改机位。
