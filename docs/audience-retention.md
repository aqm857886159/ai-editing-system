# 观众心理与平台数据：剪辑决策从哪里来

[视觉编辑指南](visual-editing.md)回答"这句话要不要加效果"，本文回答更前面的问题：**观众在第几秒、因为什么离开，以及这些行为怎样变成平台数据。** 结构、开头、素材密度和结尾都从这里倒推。拿到一段素材具体怎么排（选题、开头、顺序、删减、效果位置），见 [观众视角编排](viewer-flow.md)。

## 证据等级（先读）

核查日期：2026-10-25。

- **官方可查**：YouTube 的观众留存报告会标出"跳过或离开"的下降点（dips），视频需至少 60 秒、100 次观看才显示，并可对比近期同长度视频的典型留存。[YouTube 帮助](https://support.google.com/youtube/answer/9314415)。抖音公开说法是多目标推荐，但没有公开各指标权重。
- **创作者经验，不是平台规则**：网上流传的"2 秒跳出率""5 秒完播率""完播率占 40% 权重""完播率 30% 以上算好"等阈值，均未找到官方出处（例：[人人都是产品经理](https://www.woshipm.com/operate/6200947.html)、[B 站专栏](https://www.bilibili.com/read/cv45263020)）。本仓库只把它们当作**观众行为的分段**来设计，不当作及格线。
- **本仓库的真实依据**：自己账号的后台曲线。每条片发布后把留存曲线的下降点写进该项目的 `review.md`，规则随数据修正。

## 观众的四道关口

| 时间 | 观众在想什么 | 对应数据 | 剪辑上必须做到 |
|---|---|---|---|
| **0–2 秒：刷到** | "这是什么？要不要停？" | 跳出率、首帧点击 | 首帧就有东西在动或有大字；第一句直接给结果、冲突或反常识，不寒暄、不自我介绍；封面和首帧说同一件事 |
| **2–5 秒：判断相关** | "跟我有关吗？值得看完吗？" | 5 秒留存 | 说中观众的处境，并给出承诺：看完能得到什么。承诺要具体（"最后给你三步"胜过"干货满满"） |
| **5 秒–结尾前：持续** | "还在讲我关心的吗？我还跟得上吗？" | 平均观看时长、完播率、曲线下降点 | 一个贯穿全片的问题做主线（开放式悬念）；每段以观众心里的问题开场；约每 40–60 秒给一个落点（判断、反转、证据）；抽象处立刻配画面；删重复 |
| **结尾：行动** | "这对我有什么用？要不要留下？" | 收藏、点赞、转发、评论、关注 | 兑现开头的承诺；给一个能带走的工具；回扣开头形成闭环；评论引导问一个具体、好回答的问题 |

## 每个数据背后的观众动机

| 数据 | 观众为什么这样做 | 内容和剪辑能提供什么 |
|---|---|---|
| 收藏 | "以后要用" | 清单、步骤、提示词、框架图。知识类内容收藏通常多于点赞，结尾工具要做成能截图保存的一张画面 |
| 点赞 | "说得对 / 说出了我的感受" | 被说中的处境、清楚的判断、真诚的个人经历 |
| 转发 | "这能代表我的观点 / 对朋友有用" | 一句能脱离上下文成立的金句；一个反常识但讲得通的判断 |
| 评论 | "我有话说" | 开放但具体的问题；可以讨论的立场（不靠制造对立） |
| 完播 / 平均时长 | "一直想知道下一步" | 悬念主线、节奏、每段的新信息 |
| 关注 | "这个人以后还会给我这种东西" | 清楚的个人身份和系列感 |

## 内容传播的几条规律（本仓库的工作假设）

1. **一片一个核心判断。** 能用一句话复述；所有段落都为它服务。
2. **反常识，但必须讲得通。** 只有冲击没有推导会被当成标题党；推导要能让观众自己得出结论。
3. **具体胜过抽象。** 每个抽象结论后面跟一个画面、例子或数字。
4. **先说中处境，再讲道理。** 观众先认出自己，才会把后面的分析当成"在讲我"。
5. **讲道理时用"我"，不用"你应该"。** 先讲自己怎么踩坑，说教感会小很多。
6. **深度不靠删，靠递法。** 每层分析先抛问题、再给画面、再给落点，深内容也能留住大多数人。

## 发布后的复盘

1. 先补公开数据：`python3 scripts/tikhub_douyin.py plays <抖音号>` 拉全部作品的播放量，`stats` 算每百次播放的赞、藏、转，和账号中位数比（不用登录）。有后台权限时，再打开留存曲线，标出每个明显下降点的时间码。
2. 对照成片判断原因：**不懂 / 不信 / 无聊 / 画面错位 / 承诺已兑现**（最后一种是正常离开）。
3. 记入 `projects/<…>/review.md` 和 `data/projects.csv`；同类原因出现两次以上，改本文或视觉指南。
