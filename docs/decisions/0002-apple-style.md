# 0002 视觉统一为 Apple 风（2026-10-03）

> 历史决策记录：保留当时选择与被否方案。2026-10-21 后的现行风格以 [taste](../taste.md) 为准；蓝／红为默认强调示例，画幅参数和封面创意不受这次旧片限制。

- 用户原话：「字幕和卡片不太优雅……我喜欢 Apple 的设计，苹果风那个范」+「白字下面加个背景」。
- 决定：字幕 = 白字 + 圆角深色半透明底；卡片 = 玻璃质感；强调色仅系统蓝/红；分段控件替代彩色 pill。
- 被否掉的：黄字黑描边字幕（`yellow-impact`）、彩色色块行、emoji 星标。
- token 与代码见 `templates/`。
