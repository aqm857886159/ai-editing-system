# dbskill 在本仓库中的用途

这些资料提供策划、开头和文案的思考方法，不另建制作规范。当前执行以 [CLAUDE.md](../../CLAUDE.md)、[workflow](../workflow.md) 和 [内容包装规则](../content-packaging/README.md) 为准；`source/` 保存引用快照，不把快照中的固定口吻、数量或历史案例升级为所有视频的默认要求。

- 选题、开头、顺序和删减的做法已经整理进 [观众视角编排](../viewer-flow.md)，先读它；要看原文时读 [dbs-title-cover-intro](source/dbs-title-cover-intro.SKILL.md)（选题梯子、标题封面开头一个许诺、冷开场）和 [dbs-script-flow](source/dbs-script-flow.SKILL.md)（逐段找划走点）。
- 找观看理由时，可读 [dbs-content](source/dbs-content.SKILL.md)、[dbs-resonate](source/dbs-resonate.SKILL.md)；[dbs-hook](source/dbs-hook.SKILL.md) 是旧版，和 title-cover-intro 冲突时以后者为准。提炼真实处境和一个内容承诺，不能为了“痛点型”硬造冲突、强加开头大字卡或改变原意。
- 写标题时可用 [dbs-xhs-title](source/dbs-xhs-title.SKILL.md) 找角度；公式是候选方法，不要求同时凑两种张力、固定排比或逐句套格式。使用过的公式记真实编号，自拟可记 `formula_id: original`。候选数量、字数及实际平台校验由内容包装规则和发布 Skill 维护。
- 写简介只概括本片交付，不固定“先结果、再五道防线、最后三件事”；不给非推广视频默认塞 Nomi 链接。历史作品里的 Star、下载或用户数字须重新核实，不能作为新片证明。
- 复用内容单元时参考 字段规范、来源命名 和 去重与版本。保留来源、边界和版本，只复用方法与经过核验的材料，不复制旧稿的事实口径。

原“AI 编程工作体系”案例留在 对应项目复盘，不再混作通用执行步骤。素材真伪、效果选型及独立审稿分别由对应规则维护，避免在 dbskill 摘要重复一遍。
