# 四平台发布操作参考

以下来自 2026-10-21 的实际操作，是定位线索，不是永久选择器。先读当前页面；遇到布局变化按可见标签重新定位。四个平台都需要用户明确授权发布、本人账号和最终视频，不能以单个平台成功代替其他平台。

## 抖音

- 上传完成后填标题、描述及话题。进入“选择封面”，分别上传横版 4:3 和竖版 3:4，查看两个预览和平台质量提示。
- 内容自主声明按真实内容选；观点类录屏可选“个人观点或见解”，不能把选项当作通用模板。
- 发布后会回到内容管理。列表可能短暂延迟，使用“搜索作品”查询本次标题，等待结果更新，核对时长、日期和“已发布”。
- 标题可能打开新标签的作品详情；保存这个可见链接与“作品状态正常”凭证。未取得分享 URL 时，管理详情链接可以作为账号内回查入口，不猜公开 URL。
- 本人验证完成只表示该阻断已解除；本人能在弹层播放待审作品，也不代表公开通过，仍看当前管理状态。
- 富文本描述有过填入后追加而非替换的情况。发现不一致时使用受支持的全选／替换再读回，不把 API 调用成功当成文本准确。

## 小红书

- 上传后填写短标题和正文；平台实时字数、可见范围和高清识别结果一并检查。
- 封面入口可能要先点击缩略图，再点“编辑封面”。上传 3:4 图片后，**进入“裁剪”明确选择 3:4**。横屏视频的默认 4:3 裁剪会切掉竖封面的上方文字。
- 点“完成”并等保存结束，切换“封面预览”，用信息流卡片核验完整文案和人物。仅看上传缩略图不足以验收。
- “发布”可能位于页面底部浮动区域。语义定位失败时先查 DOM/AX 或最新截图，必要时用当前绑定页面的受支持原生操作；不要用猜测的旧坐标，也不要用脚本触发表单事件。
- 发布后进入“笔记管理”，核对标题、时长、发布时间和审核标签。URL 中已有 `published=true` 不能证明本次发布成功。“审核中”记录为 `processing`，暂时没有公开链接就留空。
- 同名作品进入选中的“已发布”列表可记录 published；公开详情是否能访问另记。有时创作后台已登录而公共站点还要求登录，或作品页暂不可浏览；这不自动推翻管理状态，也不能把由 ID 拼成的地址当作已核验分享链。

## B站

- 上传页涉及协议时按当前工具规则处理；本次已经确认过的同一动作不反复询问。
- 分别配置“首页推荐封面（4:3）”和“个人空间封面（16:9）”。不要把“双比例同步改动”误当作两张图已经分别设置。
- 填写标题、简介、分区和标签。富文本简介与动态文案不是同一个字段。
- 标题输入曾出现填入后回退为文件名：移焦后读回实时 `value`。如果回退，使用全选后正常逐字输入并再次读回，不以 `.fill()` 成功当作保存成功。
- 点击“立即投稿”后等“稿件投递成功”；再查看进度/视频管理，取得 BV 链接。存在公开详情页且标题/正文正确时可以记录 `published`；只有成功提示而状态未知时记录 `submitted`。
- 标签被表单拒绝时，只选择真实相关且被接受的标签，记录实际结果；不机械把清晰度／文件名误当内容标签。AI 声明按实际生成封面、视频等内容和当前选项填写，不默认整片由 AI 生成。

## X

- 使用专门短帖，遵守当前编辑器的加权字数校验。等待视频 `Ready` 再发布。
- 这次普通编辑器的“Edit media”只提供 Captions / Content warning，没有自定义缩略图入口。能力不存在时使用视频首帧/平台默认缩略图，记录限制；不要谎称已应用 16:9 封面，也不要临时多发一条封面帖。
- 成片已烧录字幕时，另传 SRT 是可选的可访问性补充，需留意可能重复显示字幕。
- 点击 Post 后等“Your post was sent”，从 View 或本人最新帖子取得完整 status URL。通知消失时可直接进入刚刚观察到的同一链接；不要再次发布。
- 按钮点击后仍停留在编辑器且结果未知，先查看本人最新帖子是否已存在同内容；确认未发出并解决可见阻碍后才重试。帖子文本与视频时长一起核对。

## 回执与恢复

每个平台写入 `delivery-status.json`：实际上传文件、最终文案、比例、账号显示名、时间、状态、详情/管理链接、回执文件和待办。发布状态可能继续变化，记录 `checked_at`，不要把旧审核状态当作长期事实。

中断后先读取记录和当前管理页；已发布不重投，审核中不重投。上传失败可以在确认没有对应作品后重试；无法确定是否已提交则标 `unknown`，先核查。某个平台卡住不妨碍完成其他已授权的平台。不要为了省一次确认接受新的法律条款、改密码或绕过浏览器安全检查。
